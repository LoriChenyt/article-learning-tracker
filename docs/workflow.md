# 工作流程与发布边界

## 1. 在本地取得数据

通过浏览器开发者工具导出包含响应内容的 HAR。HAR 只作为本地输入，不进入项目目录，也不发送给第三方服务。

## 2. 本地生成学习清单

运行程序时可以同时传入多个 HAR。程序从 JSON 响应中的 `article_list` 数组提取文章，使用字段白名单生成 CSV。

## 3. 验证结果

命令结束时会显示：

- 唯一文章数量
- 已发现编号的最小值和最大值
- 编号范围内的缺号

结果验证包括抽查标题、日期和链接，以及确认 CSV 中不存在登录或会话字段。

## 4. 管理学习进度

CSV 可以直接用 Excel 或其他表格工具打开。真实学习状态和笔记属于私人数据，适合保存在本机的 `output/` 或 `private/` 目录。

## 5. 发布到 GitHub

适合公开的内容：

- 源代码
- 自动测试
- 虚构示例
- 操作文档

不公开的内容：

- 原始 HAR
- 真实文章目录
- Cookie、请求头或会话令牌
- 个人学习状态和笔记

提交前运行：

```powershell
git status --short
git ls-files
```

推送前的文件列表中不应包含 `.har`、真实 CSV、Excel 学习表或私人数据。
